# Задание 15. Поиск по хранилищу (AQL)

**Что делаем:** ищем артефакты запросом на языке AQL — как в SQL,
только по файлам хранилища.

**Зачем:** когда артефактов тысячи, искать их мышкой невозможно.
AQL-запросы используют в скриптах: «найди все файлы старше месяца»,
«найди все версии myapp».

## Шаг 1. Найдите все файлы myapp

```bash
cd ../task15-aql
```

ВПИШИТЕ пароль:

```bash
curl -s -u admin:"Vorop1612)" -X POST \
  -H "Content-Type: text/plain" \
  -d 'items.find({"repo": "myapp-local", "name": {"$match": "myapp*"}})' \
  http://localhost:8081/artifactory/api/search/aql
```

Разбор запроса:
- `items.find({...})` — найти файлы;
- `"repo": "myapp-local"` — в нашем репозитории;
- `"$match": "myapp*"` — имя начинается с `myapp` (`*` — любые символы).

В ответе — массив `results` со всеми найденными файлами и их путями.

## Шаг 2. Найдите только версию 1.0.0

Измените запрос: замените условие по имени на условие по пути.
ВПИШИТЕ вместо `____`:

```bash
curl -s -u admin:"Vorop1612)" -X POST \
  -H "Content-Type: text/plain" \
  -d 'items.find({"repo": "myapp-local", "path": {"$match": "myapp/1.0.0*"}})' \
  http://localhost:8081/artifactory/api/search/aql
```

Подсказка: путь файла версии 1.0.0 начинается с `myapp/1.0.0`.
Не забудьте звёздочку в конце.

## Результат

Второй запрос возвращает ровно один файл — `myapp/1.0.0/myapp-1.0.0.tar.gz`.

**В отчёт:** ваш итоговый AQL-запрос.
