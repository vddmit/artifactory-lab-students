# Задание 11. Выпуск новой версии

**Что делаем:** меняем приложение, выпускаем версию 1.0.1 и публикуем её
рядом с 1.0.0.

**Зачем:** версии не затирают друг друга — хранится вся история релизов.
Из любой версии можно восстановиться.

## Шаг 1. Измените приложение

```bash
cd ../task06-build-app
echo "print('hello from myapp v1.0.1')" > myapp/main.py
echo "1.0.1" > myapp/VERSION
```

## Шаг 2. Соберите архив новой версии

```bash
tar -czf myapp-1.0.1.tar.gz -C myapp .
```

## Шаг 3. Опубликуйте

ВПИШИТЕ пароль:

```bash
curl -u admin:"Vorop1612)" -T myapp-1.0.1.tar.gz \
  http://localhost:8081/artifactory/myapp-local/myapp/1.0.1/myapp-1.0.1.tar.gz
```

Обратите внимание: версия встречается в URL дважды — в пути и в имени файла.

## Шаг 4. Проверьте в интерфейсе

**Artifacts → myapp-local → myapp** — теперь там две папки: `1.0.0` и `1.0.1`.

Сравните SHA-256 версий (вкладка Checksums у каждого файла):
они должны **различаться** — содержимое-то разное.

## Результат

В репозитории две версии артефакта.

**В отчёт:** скриншот дерева с двумя версиями.

> в `slides.html`.
